**VISUAL STYLE CONCEPT**

**Atmosphere:**
Immersion into deep space of financial markets. Interface breathes, elements float in space, creating sensation of weightlessness and control simultaneously. Darkness soothes, allowing focus on essentials.

**Tactility:**
Every button is a physical object. You press—it responds, depresses, reacts. Interface isn't a flat screen but a spaceship control panel. Sense of materiality when working with digital assets.

**Light and Shadow:**
Light source seemingly positioned above screen. Elements cast soft, blurred shadows into darkness, creating depth and hierarchy without aggression. Active elements glow from within, naturally attracting attention.

**Emotional Palette:**
Calmness of darkness. Pulsating energy of accent colors—green instills confidence, red demands caution, blue remains neutral. Colors don't shout—they guide.

**Movement:**
Smooth, confident, unhurried. Elements appear and disappear like breathing. No abruptness—only natural transitions, as if interface is living organism.

**Philosophy:**
Professional's minimalism. Distracting details removed, only critical remains. Beauty in functionality. Each element earned its place. Premium through simplicity.

**Space:**
Air between elements is as important as elements themselves. Grouping is intuitive—related stays close, different stays separated. Gaze glides freely across interface without stumbling.

**Character:**
Serious but not cold. Technological but humane. Professional tool you trust. Premium without ostentatious luxury.

**TRADING APP DESIGN SYSTEM**

**Color Palette:**
• Background: dark gray/black (#1a1d29, #0f1015)
• Elements: gray gradients (#2a2d3a → #1f2230)
• Accents:
  - BUY/green (#00d395, #10b981)
  - SELL/red (#ff5252, #ef4444)
  - ORDER/blue (#5b8cff)
• Text: white (#ffffff), gray (#8b8e98) for secondary

**Interface Style:**
• Neomorphism + Glassmorphism
• Volumetric elements with multi-layer shadows:
  - Outer shadow: rgba(0,0,0,0.5) blur 20-30px
  - Inner highlight: rgba(255,255,255,0.05)
• Semi-transparent overlays for dropdown menus
• "Elevated" effect for active buttons

**Typography:**
• Font: SF Pro/Inter/Roboto (sans-serif)
• Sizes: 12px (small), 14-16px (body), 18-22px (headings)
• Weight: Regular (400), Medium (500), Semibold (600)
• Uppercase for button labels
• High text contrast

**Components:**

*Buttons:*
• Border-radius: 12-16px
• Padding: 16-20px vertical, 20-32px horizontal
• States: default/hover/active/disabled (opacity 0.4-0.5)
• Shadows: 2-3 layers with varying blur
• Active: lighter + elevated (more shadow)

*Modal Windows:*
• Backdrop: rgba(0,0,0,0.6-0.8) blur
• Container: dark with border 1px rgba(255,255,255,0.1)
• Appearance animation: fade + scale

*Icons:*
• Style: line-based, 1.5-2px stroke
• Size: 20-24px
• Color: white/gray, accent when active

**Grid and Spacing:**
• Gap between elements: 8px, 12px, 16px
• Margin for button groups: 12-16px
• Container padding: 16-24px
• Structure: modular grid system

**Hierarchy:**
• Size: large = important (BUY/SELL)
• Color: bright = actions, gray = options
• Position: center = primary, edges = secondary
• Grouping: close elements are related

**States:**
• Default: gray background + white text
• Selected: accent color + raised effect
• Disabled: opacity 50% + no shadow
• Hover (desktop): slight brightening + scale 1.02

**Animations:**
• Transition: 200-300ms ease-out
• Hover/press: transform + shadow
• Modals: fade + slide/scale
• Loaders: skeleton screens in dark theme

**Key Features:**
• Minimalism without excessive elements
• Focus on actions (trading buttons)
• Contextual grouping (order types together)
• Visual feedback for all actions
• Adaptive sizing for content
