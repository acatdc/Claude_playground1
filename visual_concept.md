# Onyx DEX Swap - Художественная концепция интерфейса

## 1. Философия и характер

### Визуальная идентичность
Интерфейс DEX — это **пространство глубокого космоса финансовых рынков**. Не просто темная тема, а погружение в среду, где элементы существуют в невесомости, где тьма успокаивает и позволяет сфокусироваться на главном.

**Характер:**
- Серьезный, но не холодный
- Технологичный, но человечный
- Профессиональный инструмент, которому доверяешь
- Премиальность без показной роскоши

### Эмоциональная суть
**Спокойствие темноты.** Пульсирующая энергия акцентных цветов — зеленый вселяет уверенность, красный требует осторожности, синий остается нейтральным. Цвета не кричат — они направляют.

**Минимализм профессионала.** Убрано все отвлекающее, оставлено только критически важное. Красота в функциональности. Каждый элемент заслужил свое место. Премиальность через простоту.

## 2. Цветовая палитра и эмоциональная нагрузка

### 2.1 Базовые цвета
**Фоны (темная основа):**
- Primary background: `#0f1015` — бесконечность космоса
- Secondary background: `#1a1d29` — приподнятые поверхности
- Card backgrounds: градиент `#2a2d3a → #1f2230` — объемность элементов

**Философия темноты:**
Темнота — не просто черный фон. Это многослойное пространство с тонкими переходами, где каждый уровень имеет свой оттенок глубины. Фон не плоский — он дышит.

### 2.2 Акцентные цвета (семантика и эмоция)

**Зеленый (действие, уверенность):**
- Primary: `#00d395` — яркая энергия покупки
- Secondary: `#10b981` — стабильная поддержка
- **Применение:** кнопка Connect Wallet, положительные метрики (APY), успешные состояния
- **Эмоция:** уверенность, рост, движение вперед

**Красный (предупреждение, важность):**
- Primary: `#ff5252` — требует внимания
- Secondary: `#ef4444` — критическая информация
- **Применение:** высокий slippage, ошибки, sell actions
- **Эмоция:** осторожность, критичность

**Синий (нейтральность, информация):**
- Primary: `#5b8cff` — спокойная информативность
- **Применение:** token icons (USDC), нейтральные действия, ссылки
- **Эмоция:** стабильность, доверие, нейтральность

**Белый и серый (иерархия текста):**
- Pure white: `#ffffff` — главные значения, заголовки, активный текст
- Medium gray: `#8b8e98` — вторичная информация, labels
- **Принцип:** яркость = важность

### 2.3 Использование цвета для иерархии
Цвет не украшение — это **навигационный инструмент**:
- Яркие цвета = действия, требующие внимания
- Серые тона = опции и настройки
- Белый = критически важная информация
- Акценты = эмоциональная окраска действия

## 3. Материальность и тактильность

### 3.1 Neomorphism — физичность в цифровом
Каждая кнопка — это **физический объект**. Нажимаешь — она отвечает, продавливается, реагирует. Интерфейс не плоский экран, а панель управления космическим кораблем. Ощущение материальности при работе с цифровыми активами.

**Принципы объемности:**
- Элементы не лежат на фоне — они **выступают** из него или **утоплены** в него
- Многослойные тени создают глубину
- Подсветка сверху имитирует источник света

### 3.2 Слои теней и глубина
**Внешние тени (elevation):**
```
Soft shadow:    0 4px 12px rgba(0, 0, 0, 0.5)
Medium shadow:  0 8px 24px rgba(0, 0, 0, 0.4)
Strong shadow:  0 12px 32px rgba(0, 0, 0, 0.6)
```
- Blur radius: 20-30px для мягкости
- Spread: 0 (естественное рассеивание)
- Цвет: всегда черный с прозрачностью, не серый

**Внутренние highlights (объемность):**
```
Inner glow: inset 0 1px 0 rgba(255, 255, 255, 0.05)
```
- Создает эффект света, падающего сверху
- Едва заметен, но критичен для ощущения объема

**Философия света:**
Источник света как будто расположен над экраном. Элементы отбрасывают мягкие, размытые тени в темноту, создавая глубину и иерархию без агрессии. Активные элементы светятся изнутри, естественно притягивая внимание.

### 3.3 Glassmorphism — полупрозрачность и воздух
**Dropdown меnus и modals:**
- Backdrop: `rgba(0, 0, 0, 0.7)` с blur 12px
- Container background: полупрозрачный с `backdrop-filter: blur(20px)`
- Border: `1px solid rgba(255, 255, 255, 0.1)` — едва различимая грань

**Эффект:** элемент существует в пространстве, но через него проникает контекст. Не полная изоляция, а мягкое разделение.

## 4. Типографика как визуальный элемент

### 4.1 Выбор шрифта
**SF Pro / Inter / Roboto** — современный гротеск с геометрической точностью

**Почему:**
- Высокая читаемость на темных фонах
- Нейтральный характер (не отвлекает от контента)
- Профессиональный тон
- Отличная поддержка кириллицы и цифр

### 4.2 Визуальная роль весов шрифта
Вес шрифта — это не только размер, это **визуальная масса**:

**Semibold (600):**
- Визуально "тяжелые" элементы
- Кнопки, заголовки, критические значения
- Притягивают взгляд

**Medium (500):**
- Сбалансированная видимость
- Input values, названия токенов, метрики
- Устойчивое присутствие

**Regular (400):**
- Легкий, не доминирующий
- Описания, labels, вспомогательный текст
- Фоновая информация

### 4.3 Uppercase для кнопок — психология
Uppercase текст на кнопках (опционально):
- **Визуальный вес:** выглядит солидно
- **Читаемость:** короткие слова (SWAP, MAX) легко сканируются
- **Характер:** технологичность, профессионализм

**НО:** для "Connect Wallet" можно сохранить регистр для человечности

## 5. Состояния элементов — визуальная обратная связь

### 5.1 Default (покой)
- Серый фон с градиентом
- Белый текст
- Мягкая тень (low elevation)
- **Ощущение:** элемент готов к взаимодействию

### 5.2 Hover (предвкушение)
- Легкое осветление фона (+5% brightness)
- Тень становится чуть сильнее
- Transform: `scale(1.02)` — едва заметное увеличение
- Transition: 200ms ease-out
- **Ощущение:** элемент откликается на присутствие курсора

### 5.3 Active / Pressed (действие)
- Фон становится ярче (акцентный цвет для кнопок действия)
- Тень усиливается (elevated effect)
- Возможно: легкий сдвиг вниз (`translateY(1px)`)
- **Ощущение:** кнопка "нажата", физическая реакция

### 5.4 Disabled (недоступность)
- Opacity: 0.4-0.5
- Тени исчезают или минимальны
- Cursor: not-allowed
- **Ощущение:** элемент есть, но не активен

### 5.5 Selected / Active (выбор)
- Акцентный цвет фона или border
- Более яркий текст
- Elevated эффект (приподнятость)
- **Ощущение:** этот элемент сейчас в фокусе

## 6. Анимации и движение

### 6.1 Философия движения
**Плавное, уверенное, неспешное.** Элементы появляются и исчезают, словно дыхание. Никакой резкости — только естественные переходы, как будто интерфейс — живой организм.

### 6.2 Timing функции
**ease-out (основная):**
- Быстрый старт → плавное затухание
- Ощущение отзывчивости
- Использование: 90% анимаций

**ease-in-out (модалы):**
- Симметричное ускорение и замедление
- Для появления/исчезновения overlay elements

### 6.3 Duration (длительность)
- **Micro-interactions:** 150-200ms (hover, focus)
- **Transitions:** 250-300ms (state changes)
- **Modals/Overlays:** 300-400ms (appearance)

**Принцип:** быстро достаточно, чтобы не раздражать, медленно достаточно, чтобы заметить качество

### 6.4 Типы анимаций

**Hover/Press:**
```
transform: scale(1.02)
box-shadow: elevation change
background: brightness shift
```

**Modals (появление):**
```
opacity: 0 → 1
transform: scale(0.95) → 1
backdrop: blur 0 → 12px
```

**Loaders (ожидание):**
- Skeleton screens в темной теме
- Пульсация opacity: 0.4 → 0.6 → 0.4
- Smooth, endless loop

## 7. Иконография

### 7.1 Стиль иконок
**Line-based (контурные):**
- Stroke width: 1.5-2px
- Закругленные концы (rounded caps)
- Минималистичные, геометрически точные

**Почему контурные:**
- Легкость и воздушность
- Не перетягивают внимание
- Хорошо масштабируются
- Современный визуальный язык

### 7.2 Цвет иконок (семантика)
- **Default:** white/gray — нейтральное присутствие
- **Active:** акцентный цвет — элемент в действии
- **Disabled:** gray с низкой opacity

### 7.3 Размеры (визуальная согласованность)
- 20×20px: мелкие иконки (dropdown arrows)
- 24×24px: стандартные иконки (settings, refresh)
- 32×32px: token icons
- Padding вокруг для tap targets: минимум 8px

## 8. Визуальные паттерны компонентов

### 8.1 Buttons (кнопки действия)
**Primary Action (Connect Wallet / Swap):**
- **Цвет:** зеленый градиент `#00d395 → #10b981`
- **Тени:** многослойные (outer + inner highlight)
- **Border-radius:** 14px (мягкая скругленность)
- **Hover:** осветление + scale 1.02 + усиление тени
- **Ощущение:** уверенный, безопасный клик

**Secondary/Utility (MAX, Details):**
- **Цвет:** темно-серый с полупрозрачностью
- **Border:** subtle `rgba(255,255,255,0.1)`
- **Hover:** легкое осветление
- **Ощущение:** доступная опция, не доминирует

### 8.2 Input Fields (поля ввода)
**Swap amount inputs:**
- **Фон:** темнее основного card background
- **Border:** едва заметный `rgba(255,255,255,0.05)` в покое
- **Focus:** border становится акцентным (синий/зеленый)
- **Text:** крупный (18px), жирный (500) — легко читается
- **Placeholder:** серый с opacity 0.4

### 8.3 Cards (контейнеры)
**Swap Card:**
- **Фон:** градиент `#2a2d3a → #1f2230`
- **Border-radius:** 16px (заметная мягкость)
- **Shadow:** medium elevation
- **Ощущение:** выступающая панель, четко отделена от фона

**Pool Cards:**
- **Фон:** аналогичный градиент
- **Border-radius:** 12px (чуть меньше)
- **Hover:** легкое осветление + scale 1.01 (карточка "оживает")
- **Ощущение:** кликабельный элемент, интерактивный

### 8.4 Token Selector
**Визуальная обработка:**
- **Фон:** чуть темнее input field
- **Border-radius:** 8px
- **Token icon:** 24px, четкий
- **Dropdown arrow:** subtle, 16px
- **Hover:** осветление + cursor pointer
- **Ощущение:** четкое понимание, что можно кликнуть и выбрать

### 8.5 Info Panel (информационная панель)
**Визуальная подача:**
- **Фон:** более темный, чем Swap Card (визуальное разделение)
- **Border:** тонкий `rgba(255,255,255,0.08)`
- **Text hierarchy:** labels серые (12px), values белые (14px жирные)
- **Метрики:** зеленый для положительных (APY), красный для высоких рисков
- **Ощущение:** информация "на расстоянии вытянутой руки", не мешает, но доступна

## 9. Пространство как художественный элемент

### Воздух между элементами
Пространство между элементами так же важно, как сами элементы. **Группировка интуитивна** — связанное находится рядом, разное — отделено.

**Визуальная дыхание:**
- Малые отступы (8-12px): элементы одной группы
- Средние отступы (16px): разные блоки внутри секции
- Большие отступы (24px+): отдельные логические зоны

**Эффект:** взгляд свободно скользит по интерфейсу, не спотыкаясь. Нет ощущения захламленности или пустоты — идеальный баланс.

## 10. Применение концепции к ключевым моментам

### 10.1 Момент подключения кошелька
**До подключения:**
- Кнопка "Connect Wallet" — яркая, зеленая, доминирующая
- Все остальное слегка приглушено (намек на disabled state)
- **Месседж:** "начни отсюда"

**После подключения:**
- Адрес кошелька в header — четкий, с зеленым индикатором
- Primary button меняется на "Swap" (или "Enter Amount" если пусто)
- Интерфейс "оживает" — все элементы активны

### 10.2 Ввод суммы
**Динамическая реакция:**
- При вводе в "From" → мгновенное обновление "To" (плавное fade значения)
- Info Panel обновляется: Rate, Min. Received анимируются (fade old → fade new)
- Если сумма > баланса: красная подсветка поля + предупреждение

### 10.3 Выбор токена
**Dropdown появление:**
- Backdrop затемнение + blur
- Список токенов: fade + slide down
- Hover по токенам: легкая подсветка
- Выбор: плавное закрытие + обновление UI

### 10.4 Просмотр Top Pools
**Визуальное внимание:**
- Pool cards с высоким APY: зеленый акцент на проценте
- Hover по карточке: scale + shadow elevation — "кликни для деталей"
- Иконки токенов перекрываются (overlap) — компактность + узнаваемость

## 11. Общие визуальные принципы (summary)

### Контраст
- **Высокий контраст текста:** белый на темном (минимум 7:1 WCAG AAA)
- **Низкий контраст фонов:** тонкие переходы для глубины
- **Акценты выделяются:** цвет появляется только там, где нужно внимание

### Согласованность
- **Border-radius единообразен:** 12-16px для cards, 8-12px для buttons
- **Shadows следуют системе:** soft/medium/strong, не хаотичны
- **Spacing кратно 8px:** визуальный ритм

### Отзывчивость
- **Каждое действие имеет реакцию:** hover, click, focus — всегда feedback
- **Анимации не блокируют:** UI остается responsive
- **Transitions добавляют polish:** интерфейс чувствуется качественным

### Премиальность
- **Детали имеют значение:** subtle shadows, gentle gradients, smooth animations
- **Нет шумных эффектов:** все сдержанно и элегантно
- **Качество в исполнении:** каждый pixel на месте
